=== file: velot/tl.py ===
build_windows()
├── KMeans in PCA space → spatial clusters
├── Within each cluster: sort by pseudotime
├── Create overlapping temporal windows
└── Pair consecutive windows → stored in adata.uns

compute_ot_velocity()
├── For each (source, target) window pair:
│   ├── Cost = distance² + time_penalty + knn_penalty
│   ├── Sinkhorn OT → transport plan P
│   └── Velocity = weighted displacement under P
├── Aggregate across windows (average)
└── Store velocity + confidence in adata

smooth_velocity()
├── Train small MLP: v_θ(x_pca, pseudotime) → velocity
├── Loss = confidence_weighted_regression + λ·KNN_smoothness
├── Cells without OT velocity → filled by interpolation
└── Overwrite velocity in adata (raw saved as backup)

project_to_umap()
├── For each cell: estimate local PCA→UMAP Jacobian
├── V_umap = V_pca @ J_local
└── Store in adata.obsm['velocity_umap']

velocity()
└── Orchestrates: windows → OT → smooth → project
